ИИ-помощник по выбору подарков

Помощник, который предлагает идеи подарков с учётом получателя, интересов, бюджета, повода и ограничений.

Возможности
- отправка пользовательского запроса в GigaChat
- системная инструкция и тематические ограничения из prompts.py
- поддержка контекста диалога
- команды история, очистить, выход
- сохранение переписки в chat_history.txt

Установка
1. Установить Python 3.10 или новее
2. Создать и активировать виртуальное окружение
3. Установить зависимости из requirements.txt (если файл отсутствует, сформировать его по используемым импортам: gigachat, python-dotenv)
4. Создать локальный файл .env со значениями GIGACHAT_CREDENTIALS и GIGACHAT_SCOPE
5. Убедиться, что сертификат certs/russian_trusted_root_ca_pem.crt доступен по указанному в коде пути

Безопасность
Не добавляйте .env, ключи API, токены, виртуальное окружение .venv и личные секреты в Git. Проверьте gitignore и историю коммитов перед публикацией.

Структура
- main.py — основной цикл диалога и обращение к GigaChat
- prompts.py — системные правила помощника
- chat_history.txt — журнал переписки
- day16–day19 — учебные этапы подготовки корпуса, нормализации, чанкинга и поиска

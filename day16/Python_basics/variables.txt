Переменные и типы данных в Python

Переменная — это имя, которому присваивается значение.

Примеры:
name = "Анна"       # str — строка
age = 18            # int — целое число
height = 1.65       # float — число с точкой
is_student = True   # bool — логическое значение

Чтобы узнать тип значения, используют type():
print(type(age))

Преобразование типов:
number = int("25")
text = str(100)

Списки в Python

Список хранит несколько элементов в одном объекте. Он создаётся с помощью квадратных скобок.

Пример:
fruits = ["яблоко", "банан", "груша"]

Получение элементов:
print(fruits[0])  # первый элемент
print(fruits[-1]) # последний элемент

Основные методы:
fruits.append("апельсин")  # добавить элемент
fruits.remove("банан")    # удалить элемент
fruits.sort()             # отсортировать список

Количество элементов:
print(len(fruits))

Перебор списка:
for fruit in fruits:
    print(fruit)

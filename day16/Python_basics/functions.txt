Функции в Python

Функция — это блок кода, который можно вызывать несколько раз.

Функцию объявляют с помощью def.

Пример:
def greet(name):
    print("Привет,", name)

greet("Анна")

Функция может возвращать результат с помощью return.

Пример:
def add(a, b):
    return a + b

result = add(3, 5)
print(result)  # 8

Параметры — переменные, указанные при объявлении функции.
Аргументы — значения, которые передают при вызове функции.

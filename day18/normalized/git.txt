Git — распределённая система контроля версий, созданная Линусом Торвальдсом в 2005 году для разработки ядра Linux.
Каждый клон репозитория Git содержит полную историю изменений, что позволяет работать автономно и без центрального сервера.
Основные команды: git init, git clone, git add, git commit, git push и git pull — покрывают повседневный рабочий цикл.
Ветвление в Git лёгкое и быстрое: git branch и git merge позволяют параллельно разрабатывать функции и объединять изменения.
Git хранит данные как снимки (snapshots) проекта, а коммиты идентифицируются по SHA-хешу и образуют направленный ациклический граф.
